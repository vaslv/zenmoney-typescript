# Changelog

## 0.1.0 — unpublished candidate

- Add asynchronous diff/readDiff/upsert/delete/suggest clients and full public
  entity models aligned with zenmoney-python 0.7.0.
- Add exact decimal/integer codec, preserved extensions/raw JSON and pure financial
  and catalog builders, including transfers/debts/refunds and budget clearing.
- Add explicit confidential-client OAuth helpers, redacted tokens, bounded requests,
  cancellation/deadlines and no hidden retries.
- Add shared Python sync/async/TypeScript contracts, native security/HTTP checks,
  installed-package Node/browser/MV3 acceptance and build/test-only CI.
- Document exact resource/runtime differences and separate live integration gates.

No npm/GitHub release has been published by this task. Browser storage, bank
connectors and ZenImport integration are outside this SDK release.
